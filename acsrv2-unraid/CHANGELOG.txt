# Assetto Corsa Server Manager optimized for unraid docker
This Docker will download and install the last Assetto Corsa Server Manager. I will not provide assistance for ACSM, please contact emperor servers.
You NEED a ACSM licence, please take one here : https://emperorservers.com/products/assetto-corsa-server-manager

## Recommanded Env params
| Name | Value | Example |
| --- | --- | --- |
| ACSM_FILES | Folder for ACSM Files | /home/assetto/ACSMv2UNRAID/ |
| STEAMCMD_DIR | Folder for SteamCMD | /home/steamcmd/ |
| PORT_1 | Port for the game server | 9601 |
| PORT_2 | Port for the web server | 8772 |
| PORT_3 | Port for the content manager | 8090 |
| PUID | User Identifier | 99 |
| PGID | Group Identifier | 100 |

## Run example
```
docker run --name='ACSMv2' -d \
  -e 'PUID'='99' \
  -e 'PGID'='100' \
  -p '9601:9601/tcp' \
  -p '9601:9601/udp' \
  -p '8090:8090/tcp' \
  -p '8772:8772/tcp' \
  -v '/path/to/serverfile':'/home/assetto/ACSMv2UNRAID/' \
  -v '/path/to/steamcmd':'/home/steamcmd/' \
  --restart=unless-stopped 'todry542/acsrv2:latest' 
```

This Docker was mainly edited for better use with Unraid.
